# Classroom Name Wheel

A kid-friendly, responsive name wheel spinner for classroom use.

## Features

- Add one name at a time
- Paste a roster with names separated by lines or commas
- Include or exclude each student with a simple on/off switch
- Save the roster in the browser automatically
- Works on phones, tablets, laptops, and desktops

## Local Development

```bash
npm run dev
```

Then open `http://localhost:5173`.

## Deploying to Vercel

1. Push this repo to GitHub.
2. In Vercel, import `eliaguilar/wheel-spinner`.
3. Use the default static site settings. No framework preset or output directory is needed.
